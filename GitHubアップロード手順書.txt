AI住宅積算ツール GitHub Pages本番Web版 v5.2
アップロード・更新手順
================================

【既にGitHub Pagesで公開済みの場合】
1. GitHubで現在のリポジトリを開く
2. 既存の index.html をv5.2の index.html に置き換える
3. Commit changes を押す
4. 1〜数分待って公開URLを再読み込みする
5. 画面上部のバージョン表示が「本番Web版 v5.2」になれば更新完了

※ Pages設定はこれまで通りでOKです。
Source：Deploy from a branch
Branch：main
Folder：/(root)

【新規公開する場合】
1. GitHubへログイン
2. New repository を作成
3. Public を選択
4. このフォルダ内の以下をアップロード
   ・index.html
   ・.nojekyll
   ・README.md（任意）
   ・GitHubアップロード手順書.txt（任意）
   ・料金表サンプル.xlsx（任意）
5. Settings → Pages
6. Source：Deploy from a branch
7. Branch：main
8. Folder：/(root)
9. Save
10. 数分後に表示される公開URLを開く

【v5.2：iPhoneでExcelを保存する方法】
1. STEP 7まで進む
2. 「Excel .xlsx」を押す
3. iPhoneの共有画面が表示されたら「ファイルに保存」を選ぶ
4. 保存場所（iCloud Drive / このiPhone内など）を選ぶ
5. 「保存」を押す

Excelアプリは必須ではありません。
保存した.xlsxは「ファイル」アプリに残ります。
ExcelまたはNumbersが入っている場合は、そのアプリで開けます。

【CSVを保存する方法】
1. STEP 7の「CSV」を押す
2. iPhoneでは共有画面から「ファイルに保存」を選ぶ
3. PCでは通常のダウンロードとして保存されます

【料金マスター】
・Excel / CSVを一度読み込むと、同じ端末・同じブラウザ内に保存されます。
・積算時に項目、仕様・寸法、単位をもとに自動照合します。
・単価やロス率は積算画面から手入力変更できます。
・「現在の単価を料金表に保存」で変更内容をマスターへ保存できます。
・iPhoneとPCの間では料金マスターは自動同期されません。

【注意】
・GitHub Pagesで公開したHTMLコード自体は公開情報になります。
・選択した住宅図面は、このHTMLからGitHubへアップロードされません。
・正式見積・契約・発注前には必ず元図面と照合してください。
