AI住宅積算ツール GitHub Pages本番Web版 v5.1
GitHubアップロード・更新手順
========================================

【このフォルダの中身】
・index.html
  → Webアプリ本体です。GitHub Pagesで公開するために必要です。

・.nojekyll
  → GitHub Pages用の設定ファイルです。隠しファイルとして表示されない場合がありますが、そのままアップロードしてください。

・README.md
  → v5.1の機能概要・料金マスターの説明です。

・料金表サンプル.xlsx
  → STEP 6「料金マスター」で読み込めるサンプルExcelです。
  ※中の単価は動作確認用のサンプル値です。実際の自社単価へ変更してください。

・GitHubアップロード手順書.txt
  → このファイルです。


【すでにv4 / v5をGitHub Pagesで公開している場合】
1. GitHubでAI住宅積算ツールのリポジトリを開きます。
2. リポジトリの一番上（root）にある index.html を開きます。
3. 既存の index.html を削除して、v5.1の index.html をアップロードします。
   または Add file → Upload files から同名ファイルを追加し、置き換えます。
4. .nojekyll がすでにある場合は、そのままでOKです。
5. README.mdもv5.1版へ置き換えて構いません。
6. 「料金表サンプル.xlsx」と「GitHubアップロード手順書.txt」は、
   Webアプリの動作には必須ではありません。保管・配布用としてGitHubへ置いてもOKです。
7. Commit changes を押します。
8. 数十秒〜数分待ち、これまで使っていたGitHub PagesのURLを再読み込みします。

※ GitHub Pagesの設定は変更不要です。
  Source：Deploy from a branch
  Branch：main
  Folder：/(root)


【新しくGitHub Pagesを公開する場合】
1. GitHubへログインします。
2. 右上「＋」→ New repository を選びます。
3. Repository name を入力します。
   例：ai-sekisan
4. Public を選択します。
5. Create repository を押します。
6. Add file → Upload files を選びます。
7. このフォルダ内のファイルをアップロードします。
   Web公開に最低限必要なのは index.html です。
   .nojekyll も一緒にアップロードすることをおすすめします。
8. Commit changes を押します。
9. Settings → Pages を開きます。
10. Build and deployment の Source を「Deploy from a branch」にします。
11. Branch を「main」、Folder を「/(root)」にします。
12. Save を押します。
13. 数分待つと公開URLが表示されます。
14. Visit site を押して動作確認します。


【v5.1 料金マスターの使い方】
1. 図面 → ChatGPT解析 → JSON読み込みまで進めます。
2. STEP 6「料金表を読み込んで積算」を開きます。
3. 「Excel / CSVを読み込む」を押します。
4. 料金表サンプル.xlsx、または自社で作成した料金表を選びます。
5. 読み込み後、「料金表を保存」を押すとブラウザに料金マスターが保存されます。
6. 次回以降は、同じ端末・同じブラウザなら保存済み料金マスターが自動利用されます。
7. 数量拾い結果の「項目」を照合し、仕様・寸法、単位が一致する料金を優先して適用します。
8. 一致しない項目は単価0のまま残るため、積算表で手入力できます。
9. 手入力した単価を今後も使いたい場合は「現在の単価を料金表に保存」を押します。


【料金表Excel / CSVの推奨列】
・項目            必須
・仕様・寸法      任意
・単位            任意
・ロス率%         任意
・材料単価        任意
・施工単価        任意

「項目」は必ず入力してください。
仕様・寸法と単位も入力しておくと、自動照合の精度が上がります。


【料金表サンプル.xlsxについて】
・1枚目の「料金マスター」シートを読み込み対象にしています。
・1行目の列名は削除しないでください。
・材料単価・施工単価は数値で入力してください。
・サンプル内の金額は実勢価格ではありません。必ず実際の自社単価へ変更してください。


【料金マスターの保存場所について】
料金マスターはGitHubやサーバーへ保存されるのではなく、
利用中のブラウザ内（localStorage）に保存されます。

そのため、
・iPhone Safariで登録 → 同じiPhone Safariでは次回も利用可能
・PC Chromeで登録 → 同じPC Chromeでは次回も利用可能
・iPhoneとPCの間では自動同期されない
・ブラウザのデータを削除すると料金マスターも消える場合がある
という仕様です。

別端末へ移したい場合は、STEP 6の「料金表CSV出力」でバックアップし、
別端末側でそのCSVを読み込んでください。


【Excel読み込み時の注意】
Excel（.xlsx / .xls）の読み込みにはインターネット接続が必要です。
通信環境などでExcelが読み込めない場合は、ExcelをCSV形式で保存してから読み込む方法も使えます。
