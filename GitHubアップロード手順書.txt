AI住宅積算ツール GitHub Pages本番Web版 v5.3
アップロード・更新手順
================================

【既に公開済みの場合】
1. GitHubで現在のリポジトリを開く
2. 既存の index.html をv5.3の index.html に置き換える
3. Commit changes
4. 数分待って公開URLを再読み込み
5. 画面上部が「本番Web版 v5.3」なら更新完了

Pages設定は変更不要です。
Source：Deploy from a branch
Branch：main
Folder：/(root)

【v5.3で統合した機能】
・PC / iPhoneの画像選択
・PCでPDFファイル選択・プレビュー
・料金マスター（Excel / CSV）
・保存済み料金マスターの自動適用
・手入力単価の保存
・Excel .xlsx / CSV出力
・iPhone共有シートからのファイル保存

【自社料金表の初回登録】
1. 通常どおり図面解析を行いSTEP 6へ進む
2. 「Excel / CSVを読み込む」を押す
3. 自社料金表を選択
4. 読込後、料金マスターとしてブラウザに保存される
5. 数量拾い結果と「項目」「仕様・寸法」「単位」を照合し、単価・ロス率を自動適用

一度登録すれば、同じ端末・同じブラウザでは次回以降も料金マスターが保持されます。
料金変更時は新しいExcel / CSVを読み込むか、画面上で変更して「料金表を保存」してください。

【PCでPDFを選ぶ】
STEP 1の「ファイルから選ぶ」からPDFを選択できます。
PDFはブラウザ内でプレビューできます。画像ファイルも従来どおり選択できます。

【iPhoneでExcel / CSVを保存】
STEP 7で「Excel .xlsx」または「CSV」を押します。
共有画面が表示されたら「ファイルに保存」を選択してください。
Excelアプリは必須ではありません。

【注意】
・料金マスターはブラウザのlocalStorageに保存されるため、別端末・別ブラウザには自動同期されません。
・GitHub Pagesで公開したHTMLコード自体は公開情報になります。
・図面ファイルはこのHTMLからGitHubへアップロードされません。
・正式見積・契約・発注前には必ず元図面と照合してください。
