AI住宅積算ツール 操作マニュアル

初めてご利用いただく方向け｜操作手順・トラブル対応ガイド

1. はじめに

本ツールは、住宅図面をChatGPTで解析し、図面から読み取れる数量を整理したうえで、自社の料金表を使用して概算積算を行うための補助ツールです。

図面から読み取った情報をJSON形式で取り込み、数量や単価を確認・修正しながら積算結果を作成できます。

本ツールでできること

  • 住宅図面（画像・PDF）の選択
  • ChatGPTで図面を解析するための指示文の自動生成
  • 図面から抽出された数量データの取り込み
  • 数量・仕様・算出根拠の確認と修正
  • 自社料金表（Excel・CSV）の登録
  • 材料費・施工費の自動計算
  • 積算結果のExcel・CSV出力

重要事項

本ツールは、正式見積を自動確定するものではありません。

AIが読み取れない寸法や仕様、図面に記載されていない情報は、数量が空欄になる場合があります。

正式な見積・発注・契約の前には、必ず担当者が元図面と照合してください。

2. ご利用前に準備するもの

以下の3点をご用意ください。

① 住宅図面

画像ファイル、PDFファイルなどをご準備ください。

可能な限り、文字や寸法が鮮明に読み取れる図面をご利用ください。

複数の図面がある場合は、必要に応じてまとめてご準備ください。

② ChatGPT

図面の解析にはChatGPTを使用します。

あらかじめChatGPTにログインし、ファイルを添付できる状態にしてください。

※ChatGPTのプランや利用状況によって、ファイルの添付数・容量・解析回数などに制限がある場合があります。

③ 自社料金表（任意）

自社の材料単価・施工単価を使用する場合は、ExcelまたはCSV形式の料金表をご用意ください。

料金表がない場合でも、単価を手入力して積算できます。

3. 基本操作の流れ

STEP 1｜住宅図面を選択する

  1. AI住宅積算ツールのURLを開きます。
  2. 「案件名」に、対象となる工事名やお客様名などを入力します。
  3. 「写真・画像を選ぶ」または「ファイルから選ぶ」を押します。
  4. 解析したい図面を選択します。
  5. ファイル名と選択枚数が表示されたことを確認します。
  6. 「ChatGPT用プロンプトを作る」を押します。

ポイント

図面を選択すると、画面内にプレビューが表示される場合があります。

PDFや一部の画像形式では、ブラウザによってプレビューが表示されないことがあります。

その場合でも、ファイル名が表示され、選択済みになっていれば次の操作へ進めます。

ただし、ファイルの選択ができたことと、AIが図面を解析できたことは異なります。

STEP 2｜ChatGPT用プロンプトをコピーする

プロンプトとは、AIに作業内容を伝えるための指示文です。

本ツールでは、住宅図面の数量拾いに適した指示文を自動生成します。

操作手順

  1. 「ChatGPT用プロンプトを作る」を押すと、指示文が表示されます。
  2. 案件名や図面枚数が反映されていることを確認します。
  3. 「プロンプトをコピー」を押します。
  4. コピー完了後、ChatGPTを開きます。

指示文を最初から自分で作成する必要はありません。

STEP 3｜ChatGPTに図面とプロンプトを送信する

ここが特に重要な操作です。

積算ツールで図面を選択しただけでは、ChatGPTに図面は送信されません。

ChatGPT側でも、同じ図面を添付する必要があります。

操作手順

  1. ChatGPTを開きます。
  2. 新しいチャットを開始します。
  3. メッセージ入力欄付近の「＋」や添付ボタンを押します。
  4. STEP 1で選択した住宅図面を添付します。
  5. 添付したファイルがChatGPTの入力欄に表示されたことを確認します。
  6. STEP 2でコピーしたプロンプトを貼り付けます。
  7. 図面とプロンプトの両方がそろっていることを確認してから送信します。
  8. ChatGPTによる解析が完了するまで待ちます。

よくある間違い

❌ プロンプトだけを送信する

⭕ 図面ファイルとプロンプトを一緒に送信する

図面を添付し忘れると、AIは実際の寸法や数量を確認できません。

その結果、数量が空欄になったり、正確な解析結果が得られなかったりします。

解析結果を確認する

ChatGPTから、次のようなJSON形式の回答が返ってきます。

{
  "document_summary": {
    "detected_documents": ["1階平面図"],
    "missing_recommended_documents": [],
    "notes": ["図面から確認できた数量を抽出"]
  },
  "items": [
    {
      "floor": "1F",
      "trade": "内装工事",
      "room": "LDK",
      "item": "床仕上",
      "specification": "フローリング",
      "quantity": 26.5,
      "unit": "㎡",
      "basis": "図面に26.50㎡と記載",
      "source_document": "1階平面図",
      "confidence": "A",
      "needs_confirmation": ""
    }
  ]
}

※上記は形式を説明するためのサンプルです。実際の解析結果ではありません。

JSONには、図面から確認できた数量や仕様、算出根拠などが記載されます。

回答が途中で止まった場合

ChatGPTに「JSONの続きだけを出してください」と伝えるのではなく、可能であれば「省略せず、最初から最後まで有効なJSONとして再出力してください」と依頼してください。

途中のJSONだけでは積算ツールに取り込めない場合があります。

STEP 4｜JSONを積算ツールに読み込む

  1. ChatGPTの解析結果をコピーします。
  2. AI住宅積算ツールに戻ります。
  3. STEP 4「JSONを貼り付け」の画面を開きます。
  4. コピーしたJSONを入力欄に貼り付けます。
  5. 「JSONを読み込んで表にする」を押します。
  6. 数量一覧が表示されたことを確認します。

確認するポイント

  • 数量拾いの項目が表示されているか
  • 数量が入力されている項目があるか
  • 部屋名・工種・仕様が正しいか
  • 不明な数量が空欄になっているか
  • 「要確認」の内容が表示されているか

読み込みに成功しても、必ずしもすべての数量が埋まるわけではありません。

図面から判断できない数量は、空欄のままになることがあります。

STEP 5｜数量拾い結果を確認・修正する

ChatGPTが読み取った情報を一覧表で確認します。

主な確認項目は以下のとおりです。

項目 確認内容
階 1階・2階・基礎など
工種 内装工事・基礎工事など
部屋 LDK・寝室など
項目 床仕上・基礎梁など
仕様・寸法 材料や部材の寸法
数量 AIが抽出した数量
単位 ㎡・㎥・m・箇所など
算出根拠 数量を判断した理由
信頼度 A・B・Cの3段階
要確認 担当者が確認すべき内容

信頼度について

A：図面に明記されている情報

図面に数量や寸法などが直接記載されている場合です。

B：図面の寸法から計算した情報

図面に記載された寸法を使用して数量を算出した場合です。

C：確認が必要な情報

資料不足や判読困難などにより、数量を確定できない場合です。

※信頼度Aでも、AIによる読み間違いの可能性はあります。必ず元図面と照合してください。

数量が空欄の場合

数量が空欄でも、必ずしもエラーではありません。

例えば、基礎伏図の一部だけを読み込ませた場合、基礎梁の断面寸法は確認できても、建物全体の基礎梁延長は分からないことがあります。

このような場合、AIは数量を推測せず、空欄として出力するように設定されています。

必要に応じて追加図面を確認し、担当者が数量を入力してください。

STEP 6｜自社料金表を使用して積算する

数量を確認したら、積算画面へ進みます。

初めて自社料金表を使用する場合

  1. STEP 6「単価を入力して積算」を開きます。
  2. 料金マスターの読み込み機能を選択します。
  3. 「Excel / CSVを読み込む」から自社料金表を選択します。
  4. 読み込み完了の表示を確認します。
  5. 数量表の項目と料金マスターの項目が照合され、対応する単価が反映されているか確認します。
  6. 材料費・施工費・合計金額を確認します。

料金表の登録について

登録した料金マスターは、同じ端末・同じブラウザ内に保存されます。

次回以降は、保存された料金マスターを使用して積算できます。

ただし、以下の場合は再登録が必要になることがあります。

  • 別のPCやスマートフォンで操作する場合
  • 別のブラウザを使用する場合
  • ブラウザの保存データを削除した場合
  • プライベートブラウズなど、保存が維持されない環境で利用した場合

自動計算されない場合

料金マスターと数量表の項目名・仕様・単位などが一致していない可能性があります。

料金マスターに該当項目が登録されているか確認してください。

一致しない場合は、単価を手入力して計算できます。

注意： 料金表が読み込めていても、すべての項目に自動で単価が設定されるとは限りません。単価が0円または空欄の項目がないか、必ず確認してください。

STEP 7｜積算結果をExcel・CSVで出力する

積算結果を確認したら、出力画面へ進みます。

操作手順

  1. 「出力へ」を押します。
  2. ExcelまたはCSVの出力形式を選択します。
  3. ファイルを保存します。
  4. 保存したファイルを開き、数量・単価・合計金額を確認します。

PCの場合

通常は、ブラウザのダウンロード先にファイルが保存されます。

iPhoneの場合

共有画面が表示された場合は、「ファイルに保存」などを選択してください。

保存方法は、使用しているブラウザや端末によって異なります。

4. よくあるトラブルと対処方法

Q1. JSONを読み込めませんでした、と表示される

考えられる原因

JSONの形式が正しくない可能性があります。

例えば、次のようなエラーです。

JSON Parse error: Unrecognized token '“'

このエラーは、JSON内に使用できない引用符が含まれている場合に発生します。

JSONでは、項目名や文字列を半角のダブルクォーテーション " で囲む必要があります。

正しい例

{
  "quantity": 3.95,
  "unit": "m"
}

誤った例

{
  “quantity”: 3.95,
  “unit”: “m”
}

対処方法

ChatGPTに戻り、次の文章を送信してください。

コピーして使える修正依頼文

先ほど出力したJSONを、標準的なJSON形式に修正して、最初から最後まで再出力してください。

以下の条件を守ってください。

・ダブルクォーテーションは必ず半角の " を使用してください。

・全角の “ や ” は使用しないでください。

・数量や仕様、算出根拠などの内容は変更しないでください。

・nullはそのまま維持してください。

・document_summaryとitemsを含めてください。

・省略や途中切れのない、有効なJSONを出力してください。

・説明文やMarkdownは付けず、JSONのみを出力してください。

再出力されたJSONをコピーし、積算ツールのSTEP 4に貼り付け直してください。

それでも解決しない場合

JSONが途中で切れていないか、冒頭と末尾がそろっているかを確認してください。

スマートフォンのキーボードなどで引用符が自動変換される場合もあるため、可能な限りChatGPTのコピー機能を使用してください。

Q2. JSONは読み込めたが、数量が表示されない

以下を確認してください。

① ChatGPTに図面を添付しましたか？

プロンプトだけでは図面を解析できません。

必ず図面ファイルも添付してください。

② 図面の文字は鮮明ですか？

寸法や部材記号が小さい場合、AIが読み取れないことがあります。

可能であれば、高解像度の図面を使用してください。

③ 必要な図面が不足していませんか？

例えば、基礎伏図の一部分だけでは、建物全体のコンクリート数量や鉄筋数量を算出できない場合があります。

④ JSONのquantityがnullになっていませんか？

"quantity": null は「数量未確定」という意味です。

これは読み込みエラーではありません。

必要な図面を追加し、再解析してください。

Q3. PDFを選択したが、プレビューが表示されない

ブラウザによっては、PDFのプレビューが表示されない場合があります。

ファイル名が表示されていれば、選択自体はできている可能性があります。

ただし、ChatGPTでの解析時には、PDFを改めて添付してください。

Q4. ChatGPTが図面にない数量を出力している

AIが誤って数値を推測した可能性があります。

図面と照合し、根拠が確認できない数値は採用しないでください。

必要に応じて、ChatGPTに次のように依頼してください。

図面に記載されている情報のみを根拠として、数量拾いを再実行してください。図面から確認できない数量は推測せず、quantityをnullにしてください。各数量の算出根拠も明記してください。

Q5. 自社料金表を読み込んだのに、単価が反映されない

料金マスターと数量表の項目名や仕様が一致していない可能性があります。

例えば、料金表では「フローリング施工」、数量表では「床仕上」と記載されている場合、同じ工事内容でも自動照合できないことがあります。

料金表の登録内容を確認し、必要に応じて項目名を調整するか、単価を手入力してください。

Q6. Excel・CSVが保存できない

ブラウザのダウンロード設定や、スマートフォンの保存先を確認してください。

iPhoneでは共有画面から「ファイルに保存」を選択できる場合があります。

また、別のブラウザで操作すると改善する場合があります。

5. 正確な積算結果を得るためのポイント

より正確な数量拾いを行うため、次の点を意識してください。

  1. できるだけ鮮明な図面を使用する
    文字や寸法がつぶれている図面は、読み取り精度が低下する場合があります。

  2. 関連する図面をそろえる
    平面図だけでなく、立面図・断面図・仕上表・基礎伏図・配筋図などを組み合わせると、確認できる情報が増えます。

  3. 一度に大量の図面を送信しすぎない
    図面の種類ごとに分けて解析することで、結果を確認しやすくなります。

  4. 数量の算出根拠を確認する
    数字が表示されていても、図面上の寸法や計算式と一致するか確認してください。

  5. 不明な数量を無理に確定しない
    判断できない数量は空欄のまま残し、追加資料で確認してください。

  6. 自社料金表の内容を定期的に確認する
    古い単価が残っていると、数量が正しくても積算金額に誤差が生じます。

6. 最終確認チェックリスト

積算結果を提出・共有する前に、以下を確認してください。

  • ChatGPTに必要な図面を添付した
  • JSONを正常に読み込めた
  • 数量と単位が元図面に一致している
  • 算出根拠を確認した
  • 信頼度C・要確認項目を確認した
  • 重複計上や拾い漏れがない
  • 自社料金マスターが正しく反映されている
  • 単価が0円・空欄の項目を確認した
  • 材料費・施工費・合計金額を確認した
  • 出力したExcel・CSVの内容を確認した

AIによって数量拾いの初期作業を効率化できますが、図面の解釈や数量の正確性を保証するものではありません。

特に、構造・基礎・配筋・設備などの数量については、複数の図面や仕様書の確認が必要になる場合があります。

AIによる数量拾い → 担当者による確認・修正 → 自社単価による積算

という流れでご活用ください。

正式な見積・契約・発注に使用する際は、必ず担当者による最終確認をお願いいたします。
