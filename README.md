# AI住宅積算ツール｜GitHub Pages 本番Web版 v4

このフォルダをそのまま GitHub リポジトリのルートへアップロードしてください。

## 含まれるファイル
- index.html : 本体
- .nojekyll : GitHub Pagesで静的HTMLをそのまま公開しやすくするための空ファイル
- README.md : この説明

## 動作確認
公開URLを開いた直後、画面上部に
「● システム正常 JavaScriptが正常に動作しています。」
と表示されればOKです。

その後、
1. 画像を選択
2. 「○枚選択済み」が表示
3. プレビュー表示
4. 「ChatGPT用プロンプトを作る」
5. STEP 2へ移動
の順で確認してください。

※ HEIC/HEIF画像はブラウザによっては選択できてもプレビューできない場合があります。
その場合でも選択状態は保持され、プロンプト生成には進めます。

## 重要
このツール自体はOpenAI APIを使用しません。
図面解析は利用者自身のChatGPTで行い、
結果JSONをこのツールへ貼り付ける方式です。
