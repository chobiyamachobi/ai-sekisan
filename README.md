# AI住宅積算ツール GitHub Pages本番Web版 v5.2

PC・iPhone対応、API不要で動作する住宅数量拾い・積算補助ツールです。

## v5.2 の主な機能
- 図面選択・プレビュー
- ChatGPT用数量拾いプロンプト生成
- ChatGPT JSONの貼付・表形式化
- スマートクォートやコードブロックを含むJSONの自動補正
- Excel / CSV料金マスター読込
- 料金マスターをブラウザ内に保存し、次回以降も自動適用
- 単価・ロス率の手入力修正、料金マスターへの再保存
- Excel .xlsx / CSVで積算結果を出力
- iPhone Safariでは共有シート経由で「ファイルに保存」に対応

## iPhoneでの出力
STEP 7の「Excel .xlsx」または「CSV」を押します。
共有画面が出た場合は「ファイルに保存」を選択してください。
Excelアプリが入っていなくても「ファイル」アプリへ保存できます。ExcelまたはNumbersがあれば、そのまま開けます。

## GitHub Pages
`index.html` と `.nojekyll` をリポジトリのルートに置いてください。READMEや手順書、料金表サンプルは動作には必須ではありません。
