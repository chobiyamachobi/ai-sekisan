# AI住宅積算ツール GitHub Pages本番Web版 v5.1

## v5の主な機能
- Excel / CSV料金表の読み込み
- 読み込んだ料金マスターをブラウザのlocalStorageへ保存
- 次回以降の積算で料金マスターを自動適用
- 材料単価・施工単価・ロス率を手入力で上書き可能
- 現在の積算単価を料金マスターへ再保存可能
- 料金マスターの手入力編集・CSV出力・削除

## v5.1パッケージで追加
- `GitHubアップロード手順書.txt`
- `料金表サンプル.xlsx`

## 料金表の推奨列
- 項目（必須）
- 仕様・寸法（任意）
- 単位（任意）
- ロス率%（任意）
- 材料単価（任意）
- 施工単価（任意）

※ 料金マスターは同じ端末・同じブラウザのlocalStorageに保存されます。別端末や別ブラウザには自動同期されません。
※ Excel読込にはSheetJS CDNを利用するため、インターネット接続が必要です。
※ `料金表サンプル.xlsx` 内の金額は動作確認用のサンプル値です。実際の自社単価に置き換えて使用してください。
