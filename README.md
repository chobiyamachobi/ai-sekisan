# AI住宅積算ツール GitHub Pages本番Web版 v5.3

v5.3は、これまでの主要機能を統合した版です。

- PC / iPhoneで画像図面を選択
- PCでPDF図面を選択・プレビュー
- ChatGPT用数量拾いプロンプト生成
- JSON読込・数量確認・修正
- Excel / CSV料金マスター読込
- 料金マスターを同じ端末・同じブラウザに保存
- 保存済み単価をSTEP 6で自動照合・自動計算
- 単価・ロス率の手入力変更と料金マスターへの再保存
- Excel .xlsx / CSV出力
- iPhoneでは共有シート経由のファイル保存に対応

## 料金表を読み込むタイミング
初回はSTEP 6で「Excel / CSVを読み込む」から自社料金表を登録してください。一度保存すれば、同じ端末・同じブラウザでは次回以降も保持され、STEP 6へ進んだ際に自動適用されます。

## GitHub Pages
公開に必要なのは `index.html` と `.nojekyll` です。README、手順書、料金表サンプルは説明・テスト用です。


## v5.4 お客様テストの不具合対策
- STEP 1の図面選択はブラウザ内のプレビュー用です。図面はChatGPTへ自動送信されません。
- STEP 3で同じ図面をChatGPTへ必ず添付してください。
- JSONが空欄・itemsが空配列の場合はエラーを表示します。
- JSON読み込み後、項目件数と数値数量の件数を表示します。
- 数量が未確定の項目は空欄のまま残します（推測で0や数量を埋めません）。
