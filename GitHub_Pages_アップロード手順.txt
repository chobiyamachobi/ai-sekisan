GitHub Pages 無料公開手順（v3）
================================

【アップロード】
1. GitHubへログイン
2. 右上「＋」→ New repository
3. Repository name：例 ai-sekisan
4. Public を選択
5. Create repository
6. Add file → Upload files
7. v3フォルダ内の以下をアップロード
   ・index.html
   ・.nojekyll
   ・README.md
8. Commit changes

【Pagesを有効化】
9. リポジトリの Settings
10. 左側の Pages
11. Build and deployment の Source
12. Deploy from a branch
13. Branch：main
14. Folder：/(root)
15. Save

【公開】
16. 数分待つ
17. Settings → Pages に公開URLが表示される
18. Visit site を押す
19. iPhone / PCで同じURLを開く

URL例：
https://ユーザー名.github.io/ai-sekisan/

【公開後の正常確認】
・画面上部：「システム正常」
・画像選択後：「○枚選択済み」
・画像プレビューが表示
・「ChatGPT用プロンプトを作る」でSTEP 2へ進む

【注意】
GitHub Pagesで公開したHTMLコード自体は公開情報になります。
図面ファイルはこのHTMLからGitHubへアップロードされません。
図面はブラウザ内でプレビューするだけで、ChatGPTへの送信は利用者が手動で行います。
